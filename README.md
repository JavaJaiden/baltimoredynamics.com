# baltimoredynamics.com

The Baltimore Dynamics website (Line Map). Static files, served by GitHub Pages at https://baltimoredynamics.com.

- `index.html`, `main.js`, `style.css`: the site
- `shared/`: content, the animated intro, drawings, photos and logos
- `CNAME`: the custom domain

Built from the `bd-v4/m01` source with `tools/build-site.py`.
